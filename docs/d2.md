# D2 sidecar — learned contract

Code is the source of truth: `anno.d2_dump` (extract + soften) and `anno.d2_live` (save/restore). This file is why those rules exist.

## Preview

- The editor is the **local D2 WASM sidecar** (`@terrastruct/d2` from a CDN), not VS Code and not a local `d2` binary.
- **Compile before launch:** `anno d2` / `anno d2 open` runs a **full compile** (`d2` → SVG, not `d2 validate`) before opening the preview. `validate` accepts markdown that WASM then rejects (`<gb10-lan>` as HTML). Fail → refuse to launch. `--force` opens anyway; `--no-check` skips. Missing `d2` binary → warn and launch.
- **Compile check:** `anno d2 check [name]` is the same full compile. Soften first; `--strict` = raw. Live **Check** tries raw WASM then softened.
- `anno d2` returns immediately after a passing check. The sidecar **polls/SSE** the `.d2`. Do not reopen and do not schedule a watch loop unless the user asks.
- First load needs the CDN + WASM. **Reconnect** reloads the tab. Same file prefers the **same port** so reload reconnects.
- Preview zoom: wheel / `Ctrl`+`+`/`-`/`0`, bar **+ − Fit**, drag to pan. Zoom resizes the SVG (viewBox stays put) so D2 HTML labels render; do not CSS-`scale()` the stage.

## Dump

- Write the `.d2` however it comes out: notes, `where X?`, `add Y`, headings, unclosed ` ```d2 ` fences, raw diagrams.
- Soften (`soften_comments`) turns non-statement lines into `#` so D2 can still draw. Do not require the human to write valid D2. Do not stop to tidy before dumping.
- `#` is a native D2 comment. Prefer `# notes` over wrapping the file in markdown.

## Save (do not lose the file)

- `Failed to fetch` means the **sidecar is gone**, not that the buffer was discarded. Stash is `localStorage` keyed by **file**, not port. Click Reconnect or run `anno d2 <name>` and reload.
- **Never save empty over a non-empty file.** Server returns 409; the client refuses too. An empty editor is not “local edits” — disk restore may replace it.
- An empty pane after a session is often a **blank overwrite**. Restore from git/history, then Reconnect. Do not Save while the textarea is blank.

## Graph shape (agent dumps)

- **Connect node ids**, never container ids as if they were edges’ only ends when you meant children. Declare nodes, then nest them in `container: { … }`.
- **Files are edge labels** (`build_w_vtk -> realise_webs: 01_w.vtp`), not extra nodes.
- Skip a three-column `inputs` / `algos` / `outputs` wrapper. Let `direction: right` follow the dataflow; containers are enough.
